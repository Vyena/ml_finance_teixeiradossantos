# Predicción del Flujo de Caja

Proyecto final del curso Machine Learning en Finanzas.

El objetivo es predecir el flujo neto de caja acumulado de los próximos 7 días utilizando información histórica de ventas, cobros y reembolsos.

## Datos

Los datos utilizados corresponden a información interna y confidencial de una empresa del sector turístico. Por este motivo, las bases originales no se incluyen en el repositorio público.

## Notebook

El análisis completo se encuentra en:

`proyecto_flujo_caja.ipynb`
